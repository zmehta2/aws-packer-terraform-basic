# AWS Infrastructure with Terraform and Ansible

This project demonstrates how to create AWS infrastructure using Terraform and configure it with Ansible.

## Project Overview

The infrastructure consists of:

- A VPC with private and public subnets
- A bastion host in a public subnet for secure SSH access
- 3 Amazon Linux EC2 instances in private subnets
- 3 Ubuntu EC2 instances in private subnets
- 1 Ansible controller EC2 instance
- All instances are properly tagged (OS: ubuntu or OS: amazon)

The Ansible playbook performs the following tasks on all 6 EC2 instances:
- Updates and upgrades packages
- Verifies and installs the latest Docker
- Reports disk usage for each instance

## Prerequisites

- AWS Account (AWS Academy)
- Terraform
- Ansible
- AWS CLI
- SSH key pair

## Implementation Steps

### 1. Create a New Branch for Assignment 10

```bash
git checkout -b Ansible
```

### 2. Update Terraform Configuration

Update the EC2 module to provision different instance types:

```bash
# Modify the EC2 instances module to create separate resources for each OS
cd terraform/modules/ec2_instances
```

Update the main.tf file to create:
- 3 Amazon Linux instances (with OS:amazon tag)
- 3 Ubuntu instances (with OS:ubuntu tag)
- 1 Ansible controller instance

### 3. Deploy the Infrastructure with Terraform

```bash
cd terraform
terraform init
terraform plan
terraform apply
```

This will:
- Create all AWS resources
- Generate an Ansible inventory file
- Generate an SSH config file for easy access through the bastion host
